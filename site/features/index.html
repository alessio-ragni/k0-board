Features

One short page for each thing k0 does, and why it does it.

Seven colours, one glance

Every session is a sticky note, and its colour says whose move it is — yours or Claude's.

Read more →

Kanban to work, List to plan

The same stories two ways: a board of notes for the day's work, and rows of epics, stories and tasks for planning it.

Read more →

Four modes, from asleep to across the room

Sleep, Away, Nerd, Driving: one click says how awake the machine stays while Claude Code works, lid closed included.

Read more →

Keep one session always on

Mark a note always active and k0 never closes its terminal for sitting idle — for a session left watching a deploy.

Read more →

The sessions you forget, closed for you

k0 shows what each session weighs, and after twelve idle hours closes the forgotten ones. Resume picks them up again.

Read more →

The real terminal, one click away

Every note is a real Claude Code session in its own terminal window. Double-click the note and that window is in front.

Read more →

Find any story with ⌘K

Press ⌘K, type a number, a word of the title or of the notes, and go straight to that session's terminal.

Read more →

What you actually shipped

What you did across every repository — what is online, and what only looks finished — written up like a release note.

Read more →

What changed, in your words

After an update, a page says what changed since the version you had — in your language, as plain or as technical as you like.

Read more →

Dictation that stays on your Mac

Hold Control, speak, let go — the text lands where the cursor is. Offline, in place of Wispr Flow.

Read more →

Where your week went

What every session consumed, by model, effort, repository and account — and how full your limits were, from your statusline.

Read more →

Every file a session touched

Open a repository's documents in a tab — what the session changed, a search that finds them, and one click from Claude's reply.

Read more →

Decide it, then check it

Epics, stories and tasks, discussed in rounds, every decision written down — and the finished work checked against each one.

Read more →

Arrows between notes

Drag an arrow from one note to another, across repositories, to say this one waits on that one.

Read more →

Work next door, merge back

/k0-work builds a planned story in its own git worktree, keeps a log as it goes, and merges back into the branch it came from.

Read more →

Your board, on every machine

Sign in with GitHub or Google and the board keeps a copy in k0 Cloud — your code never goes with it.

Read more →

Start with the work you already did

/k0-import puts the Claude Code sessions you already had on the board, each with a title and a line saying what it was about.

Read more →

Is it saved? Is it up?

A mark on every note and column says what is not committed or not pushed; a globe says whether the dev site is running.
