how it works

Seven colours, one glance

Every Claude Code session on the k0 board is a sticky note whose colour is its status — red when it asks you something, amber when a plan waits for your yes, blue while it works, green when it is done.

Since k0 0.1.0

A note is its status

Each Claude Code session you start from k0 is a sticky note on the board, one column per repository. There is nothing to read on it to know where it stands: the note is the colour of its status, and the colour changes by itself while the session runs.

ColourStatusWhat it means
greyBacklogjust an idea — the session has not been started
redNeeds answerit is asking you something
amberNeeds approvalit has finished a plan and waits for your yes
yellowYour turnthe terminal is idle, waiting for you to say something
blueWorkingit is working
light bluePlanningit is working inside a plan
greenDoneyou closed it

The first four are your move; the two blues are Claude's.

Why colours and not a row of tabs

With ten sessions open the question is never what is each one doing — it is which one needs me now. A red note answers that from across the room. A question asked twenty minutes ago no longer sits unseen behind three terminal windows.

How to use it

  • Install with npx k0-board and open the board.
  • Press + next to a repository, give the story a title, and Start: a real Claude Code session opens in its own terminal, and its note appears.
  • Work as you always do. When a note turns red or amber, double-click it and you are in that terminal.

The same colours light the menu bar icon, which always shows the most urgent one, and the web board k0 Cloud keeps for your phone.
